# Data Model: Felix Core Digest

**Feature**: 014-felix-core-digest
**Date**: 2026-04-04

---

## Entities

### 1. JSONL Log Entry

The atomic unit of agent activity data. One line per action, appended to a
daily per-agent file.

**Required fields** (every entry, every verbosity level):

| Field | Type | Source | Description |
|---|---|---|---|
| `ts` | string (ISO-8601 UTC) | log_action.py | Timestamp of the log write |
| `run_id` | string | log_action.py | `{agent}-{YYYYMMDD}-{HHMM}` format |
| `agent` | string | CLI argument | Agent name (e.g., `felix-admin-capture`) |
| `autonomy_level` | string | Registry lookup | `assisted`, `observed`, or `autonomous` |
| `category` | string (enum) | CLI argument | `routine`, `flagged`, `error`, `security` |
| `action` | string | CLI argument | What the agent did (e.g., `task_proposed`) |
| `target` | string | CLI argument | What the action operated on |
| `outcome` | string | CLI argument | Result (e.g., `accepted`, `error`) |

**Context block** (standard + verbose verbosity):

| Field | Type | Source | Description |
|---|---|---|---|
| `context` | object | CLI argument (JSON) | Freeform key-value pairs |
| `context.project` | string | Agent | Project or domain context |
| `context.due` | string | Agent | Due date if applicable |
| `context.priority` | string | Agent | Priority level |
| `context.vikunja_task_id` | int or null | Agent | Vikunja task ID if created |
| `context.details` | string | Agent | Additional detail text |
| `context.note` | string | Agent | Freeform note |
| `context.proposal_ref` | string | Agent | Cross-reference for generative output |
| `context.channel` | string | Agent | Delivery channel (e.g., `whatsapp`) |

**Trace block** (verbose verbosity only):

| Field | Type | Source | Description |
|---|---|---|---|
| `trace` | object | CLI argument (JSON) | Debugging/diagnostic data |
| `trace.confidence` | object | Agent | Per-field confidence scores (0-1) |
| `trace.clarification_asked` | array[string] | Agent | Fields that needed user input |
| `trace.api_calls` | array[object] | Agent | API call log entries |

**Validation rules:**
- All required fields must be present and non-empty
- `category` must be one of: `routine`, `flagged`, `error`, `security`
- String field values exceeding 120 characters are truncated with `[truncated]`
- `ts` and `run_id` are generated by log_action.py — never accepted from CLI
- `context` block is stripped when verbosity is `brief`
- `trace` block is stripped when verbosity is `brief` or `standard`

### 2. Log File

A daily JSONL file containing all entries for one agent on one day.

**Path**: `~/second-brain/agents/logs/{agent-name}/YYYY-MM-DD.jsonl`

**Rules:**
- One file per agent per day
- Multiple runs append to the same file
- Agent subdirectory created on first write
- Append-only: no existing entries modified or deleted by log_action.py
- No retention policy on raw logs (managed externally if needed)

### 3. Digest File

A per-agent daily Markdown file summarizing that agent's activity.

**Path**: `~/second-brain/notes/Agent-Logs/{agent-name}/YYYY-MM-DD-log.md`

**Content**: Human-readable Markdown generated by summarize.py from JSONL
entries. Preserves existing digest format: autonomy level header, per-run
sections, routine counts, elevated items with icons.

**Rules:**
- One file per agent per day
- Regenerated on each summarize.py run (not append-only)
- 5-day retention: files older than 5 calendar days deleted (age from filename)
- No write when no new JSONL content since last run

### 4. Overview

A consolidated Markdown file regenerated on each summarize.py run.

**Path**: `~/second-brain/notes/Agent-Logs/overview.md`

**Content**: Combines all agent digests for the current day. Includes critical
alert status.

**Rules:**
- Always represents current day only
- Regenerated on each run (replaces previous content)
- Subject to same idempotency check as digest files

### 5. Agent Registry Entry

Extended with `log_verbosity` field.

**Path**: `docs/constitution/agent-registry.json`

**New field**:

| Field | Type | Values | Default |
|---|---|---|---|
| `log_verbosity` | string | `brief`, `standard`, `verbose` | `standard` |

Added to each agent entry alongside existing `autonomy_level`, `scope`,
`team`, etc.

## State Transitions

### Log Entry Lifecycle

```
Agent determines action → calls log_action.py with structured args
  → log_action.py validates → VALID: appends JSONL entry to daily file
                             → INVALID: exits non-zero, no file write
```

### Digest Generation Lifecycle

```
Cron fires (every 15 min) → summarize.py starts
  → Checks for new JSONL content since last run
    → No new content: exits (no file writes)
    → New content:
      → Reads all agent JSONL files for today
      → Groups by agent, filters by autonomy level
      → Generates per-agent digest Markdown
      → Generates overview.md
      → Deletes digest files older than 5 days
      → Checks for critical alerts (error/security categories)
```

### Verbosity Levels

| Level | Required Fields | Context Block | Trace Block |
|---|---|---|---|
| `brief` | Written | Stripped | Stripped |
| `standard` | Written | Written (if provided) | Stripped |
| `verbose` | Written | Written (if provided) | Written (if provided) |
