# WP01 — Preserve original file mode in inbox `_atomic_write` helpers

## Objective

Fix the `_atomic_write` helper in `scripts/inbox/inject_parse_error_marker.py` and `scripts/inbox/strip_parse_error_marker.py` so that, after a write, the target file's mode matches the pre-existing mode (or `0o664` if no prior file existed). Add a single stderr log line per successful write to surface future perm regressions. Cover both helpers with unit tests, then deploy and verify end-to-end via the SC-002 canary.

## Context

The current implementation in both scripts uses `tempfile.mkstemp + os.replace`. `mkstemp` creates the temp file with mode `0o600` (writer's umask), and `os.replace` does not copy mode from the target, so the result inherits the temp file's mode and the writer's uid. When the writer is the `claude` agent user and the target was a `kgale`-owned note, the result is `claude:secondbrain 0o600` — unreadable by `ob` (Obsidian Sync daemon, runs as `kgale`). This silently breaks sync for any note the scripts touch.

See [spec.md](../spec.md), [plan.md](../plan.md), [research.md](../research.md), and [quickstart.md](../quickstart.md) for full context and decisions.

### T001 — Modify `_atomic_write` in `scripts/inbox/inject_parse_error_marker.py` [P]

**Purpose**: Preserve original target mode; default to `0o664` for new files; emit one stderr log line on success.

**Steps**:

1. Locate `_atomic_write` (currently at lines ~123–140 of `scripts/inbox/inject_parse_error_marker.py`).
2. Add `import stat` and `import sys` (if not already imported — `sys` is already imported).
3. Replace the function body with:

   ```python
   def _atomic_write(path: Path, content: str) -> None:
       """Write to a tempfile in the same directory, then os.replace.

       Preserves the original target file's mode (or applies 0o664 for new
       files) so that cross-user access (e.g. ob sync running as a different
       user) is not broken by the temp file's umask-derived 0o600.
       """
       parent = path.parent
       fd, tmp_name = tempfile.mkstemp(
           prefix=path.name + ".",
           suffix=".tmp",
           dir=str(parent),
       )
       try:
           with os.fdopen(fd, "w", encoding="utf-8") as fh:
               fh.write(content)
           try:
               mode = stat.S_IMODE(os.stat(path).st_mode)
               kind = "preserved"
           except FileNotFoundError:
               mode = 0o664
               kind = "new"
           os.chmod(tmp_name, mode)
           os.replace(tmp_name, path)
           print(
               f"INFO: atomic_write {path} mode={oct(mode)} ({kind})",
               file=sys.stderr,
           )
       except Exception:
           try:
               os.unlink(tmp_name)
           except OSError:
               pass
           raise
   ```

4. Verify imports at the top of the file include `stat` (add `import stat` if missing — it's a stdlib module, no dep change).

**Files**:
- `scripts/inbox/inject_parse_error_marker.py` (modify ~20 lines)

**Validation**:
- [ ] `_atomic_write` references `stat.S_IMODE`, `os.stat`, `os.chmod`.
- [ ] On success, exactly one `print(..., file=sys.stderr)` log line is emitted with the path, mode, and `(preserved|new)` kind.
- [ ] Exception handling still unlinks the temp file and re-raises.

**Edge cases**:
- Target does not exist (new file) → `FileNotFoundError` caught → mode `0o664`, kind `"new"`.
- Target is read-only (mode `0o444`) → preserved as `0o444`.
- Concurrent unlink of target between `os.stat` and `os.replace` → falls through to `FileNotFoundError`-style behavior (mode 0o664). Acceptable.
