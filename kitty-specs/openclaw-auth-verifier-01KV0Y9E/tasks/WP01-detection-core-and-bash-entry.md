## Objective

Build the foundational `--check` surface of `anthropic-verify`: a deterministic, read-only helper that enumerates OpenClaw sub-agents, detects per-agent SQLite auth-row shadow (which overrides the working read-through inheritance from `main`), detects drift between the plaintext credential file and `main`'s SQLite, and pings Anthropic for liveness. Output is structured findings + fingerprint-only summaries — no key values anywhere. This is the foundation for WP02 (repair), WP03 (rotation integration), and WP04 (runbook).

## Context

The `#596` incident (`felix-admin-capture` cron failures from `openclaw doctor --fix` migrating a stale `auth-profiles.json` into the agent's SQLite) showed that the OpenClaw 2026.6.x runtime treats per-agent SQLite auth rows as overriding the inheritance from `main`. The healthy state for a sub-agent is **zero rows** in both `auth_profile_store` and `auth_profile_state`. The verifier detects shadow by row-presence alone; no key-value comparison is needed (and not allowed, per the no-key-in-output invariant).

For drift, the verifier compares the plaintext file `/data/services/openclaw/secrets/anthropic` (consumed by `felix-doc-auditor-driver` and `felix-heartbeat-gate` outside the openclaw-gateway path) against `main`'s SQLite `auth_profile_store["primary"].store_json["profiles"]["anthropic:default"]["key"]` by sha256[:8] prefix. They must match; a divergence indicates a rotation that bypassed `anthropic-rotate.sh`.

The Anthropic ping uses the plaintext-file value (which is also what `main`'s SQLite holds in the healthy state) to confirm the canonical key is accepted by `api.anthropic.com`. Per spec C-008, sub-agent keys are NOT pinged individually.

This WP also delivers the test fixtures other WPs will reuse and the bash entry script that operators will invoke from the Mac via `ssh office2-claude`.

### T002 — Author `findings.py`: Finding dataclass + sanitization invariant

`scripts/security/anthropic_verify/findings.py` defines the `Finding` frozen dataclass per `data-model.md`:

```python
from dataclasses import dataclass, field
from typing import Literal, Optional

FindingType = Literal[
    "shadow", "drift", "anthropic_rejected", "network",
    "main_empty", "plaintext_missing",
]

KEY_SHAPE_PREFIX = "sk-ant-"
KEY_SHAPE_MIN_LEN = 90

@dataclass(frozen=True)
class Finding:
    type: FindingType
    target: str
    evidence: dict
    suggested_action: str

    def __post_init__(self):
        # Sanitization invariant — NEVER let a key value leak through evidence or suggested_action
        for source in (str(self.evidence), self.suggested_action):
            self._refuse_if_key_shaped(source)

    @staticmethod
    def _refuse_if_key_shaped(text: str) -> None:
        idx = text.find(KEY_SHAPE_PREFIX)
        while idx != -1:
            window = text[idx : idx + KEY_SHAPE_MIN_LEN]
            if len(window) >= KEY_SHAPE_MIN_LEN and " " not in window and "\n" not in window:
                raise ValueError(
                    "Finding rejected: contains key-shaped substring; sanitize before construction"
                )
            idx = text.find(KEY_SHAPE_PREFIX, idx + 1)

    def fmt_line(self) -> str:
        """Return one-line human-readable summary (per NFR-002)."""
        # Implementation: per-type formatter; uses only evidence keys + target + suggested_action
        ...
```

The `__post_init__` check is the linchpin of C-005 (no key in output). It runs on every `Finding` construction and refuses to instantiate if any field smells like an Anthropic key. Tests in T007 verify this by attempting to construct a Finding with a key-shaped evidence value and asserting `ValueError`.

### T003 — Author `core.py`: discovery + topology + drift compare

`scripts/security/anthropic_verify/core.py` implements the deterministic detection logic:

```python
import sqlite3, json, pathlib, hashlib, os
from typing import Optional, Iterator
from .findings import Finding

OPENCLAW_AGENTS_DIR = pathlib.Path("~/.openclaw/agents").expanduser()
PLAINTEXT_FILE = pathlib.Path("/data/services/openclaw/secrets/anthropic")
SHA_FINGERPRINT_LEN = 8

@dataclass(frozen=True)
class AgentAuthState:
    agent_id: str
    sqlite_path: pathlib.Path
    store_rows: int
    state_rows: int
    last_update_ms: int
    canonical_key_sha8: Optional[str]   # only set for agent_id == "main" when row present

@dataclass(frozen=True)
class PlaintextFileState:
    path: pathlib.Path
    exists: bool
    sha8: Optional[str]
    mode: int
    uid: int
    gid: int

def discover_agents(root: pathlib.Path = OPENCLAW_AGENTS_DIR) -> list[AgentAuthState]:
    """Glob agent dirs, return AgentAuthState for each."""
    states = []
    for agent_dir in sorted(root.glob("*/agent")):
        agent_id = agent_dir.parent.name
        sqlite_path = agent_dir / "openclaw-agent.sqlite"
        if not sqlite_path.exists():
            continue
        states.append(_read_agent_state(agent_id, sqlite_path))
    return states

def _read_agent_state(agent_id: str, sqlite_path: pathlib.Path) -> AgentAuthState:
    """SELECT counts and (for main) the canonical key sha256[:8]. No key value returned."""
    con = sqlite3.connect(sqlite_path)
    try:
        store_rows = con.execute("SELECT COUNT(*) FROM auth_profile_store").fetchone()[0]
        state_rows = con.execute("SELECT COUNT(*) FROM auth_profile_state").fetchone()[0]
        last_update = max(
            con.execute("SELECT COALESCE(MAX(updated_at), 0) FROM auth_profile_store").fetchone()[0],
            con.execute("SELECT COALESCE(MAX(updated_at), 0) FROM auth_profile_state").fetchone()[0],
        )
        canonical_sha8 = None
        if agent_id == "main" and store_rows > 0:
            row = con.execute(
                "SELECT store_json FROM auth_profile_store WHERE store_key='primary'"
            ).fetchone()
            if row is not None:
                key = json.loads(row[0])["profiles"]["anthropic:default"]["key"]
                canonical_sha8 = hashlib.sha256(key.encode()).hexdigest()[:SHA_FINGERPRINT_LEN]
        return AgentAuthState(agent_id, sqlite_path, store_rows, state_rows, last_update, canonical_sha8)
    finally:
        con.close()

def read_plaintext_state(path: pathlib.Path = PLAINTEXT_FILE) -> PlaintextFileState:
    """Read the plaintext file's fingerprint without ever returning its value."""
    if not path.exists():
        return PlaintextFileState(path, False, None, 0, 0, 0)
    st = path.stat()
    raw = path.read_bytes().strip()
    sha8 = hashlib.sha256(raw).hexdigest()[:SHA_FINGERPRINT_LEN]
    return PlaintextFileState(path, True, sha8, st.st_mode & 0o777, st.st_uid, st.st_gid)

def evaluate_topology(states: list[AgentAuthState], plaintext: PlaintextFileState) -> list[Finding]:
    """Produce findings for shadow / main_empty / drift / plaintext_missing."""
    findings = []
    main_state = next((s for s in states if s.agent_id == "main"), None)
    if main_state is None or main_state.store_rows == 0:
        findings.append(Finding(
            type="main_empty",
            target="main",
            evidence={"sqlite_path": str(main_state.sqlite_path) if main_state else "missing"},
            suggested_action="Run anthropic-rotate.sh to establish the canonical key.",
        ))
        # Skip downstream checks if main is broken
        return findings
    for s in states:
        if s.agent_id == "main":
            continue
        if s.store_rows > 0 or s.state_rows > 0:
            findings.append(Finding(
                type="shadow",
                target=s.agent_id,
                evidence={
                    "agent": s.agent_id,
                    "store_rows": s.store_rows,
                    "state_rows": s.state_rows,
                    "last_update_ms": s.last_update_ms,
                    "sqlite_path": str(s.sqlite_path),
                },
                suggested_action=f"anthropic-verify --repair  (clears per-agent rows; restart gateway afterward)",
            ))
    if not plaintext.exists:
        findings.append(Finding(
            type="plaintext_missing",
            target=str(plaintext.path),
            evidence={"plaintext_path": str(plaintext.path)},
            suggested_action="Run anthropic-rotate.sh to write the plaintext file.",
        ))
    elif plaintext.sha8 != main_state.canonical_key_sha8:
        findings.append(Finding(
            type="drift",
            target=str(plaintext.path),
            evidence={
                "plaintext_sha8": plaintext.sha8,
                "sqlite_sha8": main_state.canonical_key_sha8,
                "plaintext_path": str(plaintext.path),
                "sqlite_path": str(main_state.sqlite_path),
            },
            suggested_action="anthropic-verify --repair  (rewrites plaintext from main SQLite, atomic)",
        ))
    return findings
```

Use `with sqlite3.connect(...) as con` if you prefer the context-manager idiom; the try/finally form above is equivalent.

### T004 — Add the Anthropic ping to `core.py`

Add `ping_anthropic(key: str) -> AnthropicPingResult` using stdlib `urllib.request`:

```python
import urllib.request, urllib.error, json
from dataclasses import dataclass
from typing import Literal, Optional

@dataclass(frozen=True)
class AnthropicPingResult:
    status: Literal["ok", "rejected", "network_error"]
    http_status: Optional[int]
    model_echoed: Optional[str]
    error_summary: Optional[str]

ANTHROPIC_BASE_URL = "https://api.anthropic.com"
ANTHROPIC_PING_MODEL = "claude-haiku-4-5"
ANTHROPIC_PING_MAX_TOKENS = 8
URLLIB_TOTAL_TIMEOUT_SEC = 15

def ping_anthropic(key: str) -> AnthropicPingResult:
    """Single live ping; returns structured result; never logs the key."""
    req = urllib.request.Request(
        f"{ANTHROPIC_BASE_URL}/v1/messages",
        data=json.dumps({
            "model": ANTHROPIC_PING_MODEL,
            "max_tokens": ANTHROPIC_PING_MAX_TOKENS,
            "messages": [{"role": "user", "content": "ping"}],
        }).encode(),
        headers={
            "x-api-key": key,
            "anthropic-version": "2023-06-01",
            "content-type": "application/json",
        },
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=URLLIB_TOTAL_TIMEOUT_SEC) as resp:
            body = json.loads(resp.read())
            return AnthropicPingResult(
                status="ok",
                http_status=resp.status,
                model_echoed=body.get("model"),
                error_summary=None,
            )
    except urllib.error.HTTPError as e:
        # Scrub error text — refuse if it contains key-shape substring (paranoia)
        snippet = e.read().decode("utf-8", errors="replace")[:80]
        return AnthropicPingResult(
            status="rejected",
            http_status=e.code,
            model_echoed=None,
            error_summary=_scrub(snippet),
        )
    except (urllib.error.URLError, TimeoutError, OSError) as e:
        return AnthropicPingResult(
            status="network_error",
            http_status=None,
            model_echoed=None,
            error_summary=_scrub(f"{type(e).__name__}: {e}"),
        )

def _scrub(text: str) -> str:
    """Defensive: redact any sk-ant- substring before returning."""
    idx = text.find("sk-ant-")
    if idx == -1:
        return text
    return text[:idx] + "[REDACTED]" + text[idx + 108:]
```

The `_scrub` helper is defensive — Anthropic's API error bodies should never echo the key, but if they ever did, this stops it from reaching stdout. Add a test in T007 that injects a key-shape into a mocked error body and asserts the scrubbed output.

### T005 — Author `anthropic-verify.sh`: bash entry

`scripts/security/anthropic-verify.sh` is a thin bash wrapper:

```bash
#!/usr/bin/env bash
# anthropic-verify.sh — detect per-agent SQLite shadow + plaintext/SQLite drift
# Origin: kentonium3/kg-automation#597; companion to anthropic-rotate.sh

set -euo pipefail

SCRIPT_DIR="$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)"
MODE=""

while [[ $# -gt 0 ]]; do
  case "$1" in
    --check)  MODE="check";  shift;;
    --repair) MODE="repair"; shift;;
    -h|--help)
      cat <<EOF
Usage: $0 [--check | --repair]

  --check    (default) Detect per-agent SQLite shadow + plaintext/SQLite drift.
             Read-only; exits 0 if green, 2/3/4/5/6 per finding type.
  --repair   Clear shadow rows or rewrite plaintext from main SQLite.
             Requires explicit flag; always writes .pre-repair.<ts>.bak before mutating.
             No interactive prompt; no auto gateway restart (prints the command).

Exit codes (per spec FR-011):
  0 green   1 error   2 shadow   3 drift   4 anthropic-rejected   5 network   6 substrate-gap
EOF
      exit 0;;
    *) echo "ERROR: unknown arg: $1" >&2; exit 1;;
  esac
done

# Default to --check when invoked with no flag
[[ -z "$MODE" ]] && MODE="check"

cd "${SCRIPT_DIR}"
exec python3 -m anthropic_verify "--${MODE}"
```

The `__init__.py` (created in T005 as a small entrypoint companion) handles the dispatch:

```python
# scripts/security/anthropic_verify/__init__.py
import sys
from . import core

def main(argv: list[str]) -> int:
    if argv == ["--check"]:
        return core.run_check()
    if argv == ["--repair"]:
        from . import repair  # Lazy — WP02 lands repair.py; WP01's tests don't import it
        return repair.run_repair()
    return 1

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

`core.run_check()` is the orchestrator: discover, evaluate_topology, ping_anthropic, format findings + summary, return exit code per spec FR-011 (lowest non-zero finding-type priority wins; substrate-gap > network > anthropic_rejected > shadow > drift).
