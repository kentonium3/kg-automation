# Obsolete Workflow References Audit

**Date**: 2026-04-05
**Method**: Grep sweep of CLAUDE.md files, agent instructions, memory stores, and project docs against known-obsolete patterns from the spec-kitty CHANGELOG (`https://github.com/Priivacy-ai/spec-kitty/blob/main/CHANGELOG.md`).
**Scope**: 5 spec-kitty-initialized projects in `~/repos/` + user-global `~/.claude/CLAUDE.md` + per-project memory stores.
